# Programmable-Cubes
This project focuses on planning how a modular structure made of programmable cubes can rearrange itself from a starting layout into a desired final shape.

Each cube is able to pivot around cubes connected to it, but every movement must follow the system’s rotation rules, avoid collisions or invalid use of space, and stay within a limited number of commands. The challenge is to determine an efficient sequence of legal moves that produces a structure matching the target shape as closely as possible.

Success is measured by comparing the final arrangement with the target configuration and minimizing the remaining difference.
